# 我的家 3.2 · Safari 本地版

使用当前 PC 3.2 独立卡片版本作为程序来源。首次打开无笔记、无附件、无个人设置；通用句子库、字体与图标是程序资源。

## 在 iPhone 使用

用 Safari 打开发布链接，点分享 → 添加到主屏幕。建议添加后从桌面图标进入，再填写自己的名字并开始记录。首次保持联网，等“离线资源已就绪”；完整字体与阅读组件约 149 MB。之后不需要电脑开机。

## 数据

记录与附件仅在当前浏览器或主屏幕应用的 IndexedDB 中保存，没有网站资料数据库，也没有自动同步。不同手机、浏览器和原来的 IPA 不会自动共享数据。需要搬家时使用本地与备份中的完整 ZIP 导出/导入。清理网站数据或移除应用可能丢失资料，请保留外部备份。

## 当前功能

- 每张笔记和笔记夹独立缩放，保留原图比例的封面。
- 嵌套笔记夹，删除时二次确认，内容移至上一级，回收站可恢复。
- 笔记图片排列、图片缩放及笔记网页 ZIP、完整 ZIP 导出。
- 缩放只调整外观，不改变“最近修改”排序。
- 手机本地 API、Service Worker 离线程序缓存；无账号、无云同步入口。

## 维护

`dist/` 是发布的静态程序。`resource-audit.json` 记录精确文件哈希及零预置资料检查；仅使用程序资源白名单，未遍历用户数据、备份、附件或 maintenance。

浏览器手机尺寸、上传、持久化、文件夹删除/恢复和导出已做本地检查；未把桌面浏览器模拟等同于 iPhone Safari 真机验收。
